## 核查口径

- 酷狗累计引流**256万人次**，客户端**21万名纯新增用户**；整体项目数据，含拉新与促活，人次与人数不相加。
- 胖汪发糖机累计**8万人次参与、2.2万人次拉新及促活**；不能当作2022年某单期成果。
- 逆时光颜研究院**53条原创视频、3.1万+粉丝、60万+转发收藏**均为账号留存/累计指标。
- 小红书真实公开笔记、后期内容复盘建议、示例六图Brief分别说明，不将复盘方案称为已执行投放稿。
- 精华油/防晒/童颜面膜/洁颜霜GMV，均为**上新首月的项目/渠道整体成果**，不是某条内容的独立转化。
- 微博个人主责，酷狗其他平台统筹/审核；抖音制作剪辑、APP技术、视觉设计由对应成员承担。

## 源码与资源

`index.html` 是独立、可编辑、响应式的静态网页：13页纵向浏览；顶部章节导航；点击图片可查看 GitHub 原作品。页面内原图直接链接现有仓库的历史图片，**没有复制生成式图片来冒充历史素材**。

目前还未额外上传PDF版本。可在浏览器中使用打印/另存为PDF进行预览；最终导出以成品排版核对后为准。

## 后续迭代建议

1. 各页校对实际本人职责与历史项目细节，优先检查活动合作和小红书Brief。
2. 检查手机浏览与完整原图展示；再优化字体、视觉和图片比重。
3. 最后生成与网页一致的PDF投递版，避免两套内容不同步。

修改目标仅为 `new-media-portfolio/`，不要覆盖 `preview/v3/`。
